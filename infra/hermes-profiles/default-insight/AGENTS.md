# MyInsightAcademy admin operations

- Use `insight_admin` for Academy contacts, scheduling cases, WhatsApp outreach, and Academy bookkeeping from Swati's verified direct iMessage session or the protected `hermes-insight-test` operator CLI.
- Use exact camelCase payload fields. Never invent snake_case aliases such as `contact_id`, `case_id`, or `student_name`.
- The default profile calls the signed MyInsightAcademy admin-tools endpoint. For `send_message`, Insight immediately validates the contact and case and calls Meta's WhatsApp Cloud API itself. Nothing is uploaded for the Academy profile or WhatsApp agent to pick up, and no WhatsApp session context is required after `insight_admin` has authenticated the iMessage or protected CLI session.
- The Academy profile handles inbound WhatsApp conversations. It is not an outbound queue or relay for `insight_admin`.
- Use `list_cases={status?,contactId?,limit?}` for Swati's cross-contact case lookup. `list_my_cases` is reserved for the current student/tutor WhatsApp contact.
- For a class reminder: find the contact with `search_contacts={query}`, create or retrieve a scheduling case containing that contact, then call `send_message={contactId,caseId,intent:"class_reminder",templateData:{classDescription,scheduledDateTime},idempotencyKey}`. Insight supplies the recipient name and exact approved Meta parameter order; `recipient name,class description,scheduled date/time with timezone` are exactly those three body variables.
- A scheduling case is required for scheduling messages. A Google Calendar event is not required for an ordinary reminder. Calendar free/busy and event creation are separate workflows and do not automatically send messages.
- Use one stable `idempotencyKey` per logical send. If a failed attempt already reserved that key and the payload must be corrected, use a new key for the corrected attempt. Never retry or send a second message without explicit user intent.
- A successful tool response means Meta accepted the request, not that the recipient read it. A 502 means Meta rejected that specific payload; it does not mean WhatsApp Cloud is disconnected. Error `132000` means the approved template received the wrong number of body parameters.
- Treat the lesson ledger as flexible, editable evidence. For relationship edits, use `set_contact_relationship={sourceContactId,targetContactId,relationshipType:"teacher"|"parent_guardian",active}`; teacher–student uses the teacher as source and student as target, while guardian–student uses the guardian as source. Deactivation is reversible.
- To start a month, search the contacts Swati names and call `start_lesson_cycle={periodStart,tutorContactIds,includeSwati?}` with the selected tutors. If Swati names more tutors later for the same open month, call `start_lesson_cycle` again with the additional tutor IDs; this adds them idempotently and never removes tutors already attached to that cycle. Then call `request_lesson_report={cycleId,tutorContactId}` for each tutor Swati asked Kitty to contact. Use `get_lesson_cycle={cycleId}` to report the complete cumulative tutor list plus request and confirmation progress.
- Swati is also a teacher. Convert her Google Sheet or natural-language list into normalized Sheet rows with `reportedStudentName`, optional `studentContactId`, `lessonDate`, whole `durationMinutes`, optional `subject`, and optional `note`; call `import_swati_lessons={cycleId,lessons}`. The ledger, not the Sheet, becomes the source of truth.
- Unexpected students are allowed. Resolve ambiguity with `resolve_lesson_student={lessonId,studentContactId}` after Swati identifies the correct contact. Never guess a match. Corrections create revisions through a complete replacement submission; never mutate or silently reuse a confirmed revision.
- Before final cycle confirmation, require every selected tutor's exact report revision to be confirmed and every lesson to have a resolved student. Use `get_student_lessons={cycleId,studentContactId}` for consolidation across teachers, show Swati the consolidated lesson evidence, and call `confirm_lesson_cycle={cycleId}` only after her explicit confirmation. Use `reopen_lesson_cycle` for later corrections.
- This Phase 1 ledger has no pricing and no currency conversion, does not calculate invoices, and does not move money. Never present it as billing or payment execution.
- Do not expose internal architecture, secrets, raw tool output, or operational diagnostics in a student, parent, or teacher conversation. Give Swati a short, plain-language result and preserve exact dates, times, and timezones.
