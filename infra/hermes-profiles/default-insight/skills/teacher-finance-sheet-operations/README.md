This directory is an additive reference overlay for Swati's existing `teacher-finance-sheet-operations` skill. It is not a replacement for the installed skill or its receipt, advance-register, reconciliation, and sheet-formatting guidance.

Install `references/fee-statement-adjustment-capabilities.md` into that skill on the authorized tenant. Preserve all existing skill sections and references.

Keep `AGENTS.md` limited to the short billing-skill routing pointer and general identity/authority rules. Do not duplicate this workflow there. Do not overwrite a tenant's unrelated instructions or other profiles' skills.
